## GYM_TORCS AI Racing League

## Project Overview

This project explores AI-based autonomous driving using the GYM_TORCS racing simulation environment. It includes custom Python racing drivers and parameter-tuning experiments to investigate steering, throttle, gear shifting, and vehicle control.

## Objectives

- Develop and experiment with custom AI racing drivers.
- Tune driving parameters to improve racing behavior.
- Compare different driver implementations.
- Explore modular and configurable vehicle-control logic.

## Project Files

- `jmcncarai.py` — custom racing driver.
- `snakeoil3_jm2.py` — intermediate driver configured for a different client port.
- `snakeoil3_v1.py` — baseline driver.
- `torcs_jm_par.py` — modular driver with configurable parameters.
- `tuning-card.md` — reference for driving parameters.

## Requirements

The project uses Python and the GYM_TORCS/TORCS environment. Additional dependencies and operating-system requirements should be confirmed using the original project documentation.

## Running the Project

Follow the setup and TORCS startup instructions in the original project documentation before launching a driver. The exact commands depend on your environment and configuration.
